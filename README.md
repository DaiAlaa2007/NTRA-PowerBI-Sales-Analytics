# NTRA Power BI Sales Analytics

## 📊 Project Overview

This project was developed as part of the **NTRA Training Program**, in collaboration with my teammate **Hania**, under the supervision of **Eng. Abdelwahab**.

The project focuses on analyzing sales and customer data using **Microsoft Power BI** and transforming raw data into an interactive dashboard that provides clear business insights.

## 🎯 Project Objectives

The main objectives of the project were to:

* Analyze overall sales performance.
* Track key business performance indicators (KPIs).
* Analyze revenue, orders, and units sold.
* Understand customer behavior and customer types.
* Analyze product and regional performance.
* Examine order and payment patterns.
* Present insights through interactive Power BI dashboards.

## 🗂️ Data Modeling

We organized the data using a structured **Star Schema** consisting of a central sales fact table and multiple dimension tables.

### Main Tables

* **Fact_Sales**
* **Dim_Product**
* **Dim_Date**
* **Dim_Customer**
* **Dim_Region**
* **Dim_Store**
* **Dim_SalesPerson**
* **Dim_PaymentMethod**

This structure helped us create relationships between the different business entities and perform efficient analysis.

## 📈 Key KPIs

The dashboard includes several key performance indicators, including:

* Total Revenue
* Total Orders
* Total Units Sold
* Average Order Value
* Average Unit Price
* Revenue YTD
* Unique Customers
* Repeat Customer Rate
* Returned Orders
* Revenue with Promotion

## 📊 Dashboard & Analysis

The Power BI dashboard provides interactive visualizations for exploring:

### Sales Analysis

* Revenue performance
* Orders and units sold
* Regional sales
* Product performance
* Store performance
* Salesperson performance

### Customer & Order Analysis

* Customer types
* Unique and repeat customers
* Average order value
* Payment methods
* Returned orders
* Promotional sales

Interactive **slicers, KPI cards, charts, and visual filters** were used to make the dashboard easier to explore and understand.
